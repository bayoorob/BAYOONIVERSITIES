Architekturbeispiel Backend / Wer kennt wen?

Durchgezogene Pfeile zeigen erlaubte Typabhängigkeiten, gestrichelte Pfeile Verstöße.

Die API enthält den Controller. Request und Response liegen in Shop.ApiObjects. Der Controller verwendet diese Verträge und ruft den OrderService auf. Der Service kennt außerdem die Verträge und Persistenztypen, die er für seine Arbeit benötigt. Die rot gestrichelten Pfeile markieren verbotene Abhängigkeiten. Mit der Checkbox lassen sie sich ausblenden, damit die erlaubte Struktur allein sichtbar bleibt. Der Pfeil steht für eine statische Typabhängigkeit, nicht für einen Methodenaufruf zur Laufzeit. Die Demo nutzt eine Assembly mit getrennten Namespaces, damit der Test einen Verstoß vor einem Projektzyklus erkennt.
